# LegalEase: AI-Powered Legal Document Generator

Automated legal drafting platform built with Google Cloud Generative AI (Gemini).

## Milestones & Epics

- **Epic 1: Model Selection & Architecture**: Gemini 1.5 Pro integration with low temperature configuration for deterministic, structured drafting.
- **Epic 2: Core Functionalities**: Standard template structuring, parameter ingestion, and customizable terms.
- **Epic 3: API Logic Integration**: FastAPI endpoints handling validation, error recovery, and async generation.
- **Epic 4: Frontend Development**: Responsive form builder and markdown document review interface.
- **Epic 5: Deployment**: Containerized multi-service deployment via Docker.
